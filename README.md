# architecture-medikamente

Проектная работа 10-го спринта курса «Архитектор программного обеспечения».

Решения распределены по директориям `Task1`–`Task6` в соответствии с формулировкой задания:

- `Task1` — аудит безопасности и семь отдельных DFD;
- `Task2` — C4 Context целевой архитектуры MVP;
- `Task3` — классификация данных и реестр средств защиты;
- `Task4` — диаграмма Исикавы и приоритизированные рекомендации;
- `Task5` — обоснование Parallel run, cutover-план, откат и роли;
- `Task6` — C2 движка классификации, слои хранилища, метрики и масштабирование.

Текстовые обоснования оформлены в `README.md`, диаграммы — в редактируемом формате draw.io.
